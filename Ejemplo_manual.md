# Sistema de Inventario

Aplicación web para gestionar productos,
categorías, entradas y salidas de inventario.

## Características
- Registrar productos.
- Editar productos.
- Eliminar productos.
- Consultar existencias.
- Generar reportes.

## Tecnologías
- Frontend: React
- Backend: Node.js
- Base de datos: MySQL

## Instalación
npm install

## Iniciar aplicación
npm run dev

## Estructura del proyecto
- src/: código fuente
- public/: archivos públicos
- config/: configuraciones
- docs/: documentación adicional
